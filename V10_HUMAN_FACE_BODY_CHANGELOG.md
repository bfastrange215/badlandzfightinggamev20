# Philly Badlandz V10 — Human Face & Body Upgrade

## 3D fighter model changes
- New organic head meshes with four facial structure types (angular, broad, lean, soft), replacing sphere-only head geometry.
- All nine fighters receive custom appearance parameters for jaw, brows, nose and neck proportions.
- Added detailed eye sockets, sclera, iris, pupil, eyelid, prominent brow, shaped nose, nostrils and lips. Beard detail revised.
- Added contoured torso geometry for athletic, heavyweight, lean and female builds, replacing rounded torso primitives.
- Replaced cylindrical arm and leg renders with tapered, muscle-shaped surfaces, while retaining the fixed-length two-bone IK from V8.
- Adjusted visible joints, wrists and glove geometry to remove some of the toy-like oversized appearance.
- Lexa/Birdface has longer, layered ponytail geometry with subtle sway; Lucy/Chucky keeps short hair bunches.

## Preserved
- All nine characters and fighting stances
- Fixed-length arm and leg movement with shoulder, elbow, hip, knee and ankle articulation
- V9 North Philly rowhomes and other arenas
- Online multiplayer, synced health, abilities, CPU fighting, combos, best-of-three rounds and menus

## Limitations
- These are more detailed original procedural 3D meshes, **not photorealistic scanned / rigged commercial character models**.
- High-end facial likeness and motion capture would require licensed or user-supplied rigged GLB/FBX characters, texture maps and animation libraries.
- The environment used to package this game prevented visual browser WebGL validation. Automated renderer, rig and server logic checks passed.
